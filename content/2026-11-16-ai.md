**AI 辅助设计日报 · 11/16**

上周五之后到今天上午，有几条值得补上。

**1. Framer：Image and Shader Generation（11/12 上线）**
可直接让 Agent 生成贴合站点的自定义图、纹理或插画；把图拖进对话或在画布上选中后改主体、去背、换风格；用一句话生成 shader（halftone、bokeh、CRT、铅笔风，或「指针拖动时把图抹开」这类交互效果）；也可以改画布上已有的 Framer shader。图像和 shader 能连用：先生成一张图，再把它作为 image shader 的输入，例如变成钢笔线稿并在鼠标移动时出现墨迹涂抹。官方未公布单次 shader 消耗多少 AI credits，也没写图像模型与版权细节。

设计师 Ayoub Kada 15 日的评述指出：这解决了「先做出一个能跑的 shader」这一步，但半径、衰减、手感参数和真机性能仍要自己把关；shader 是 Framer 图层，对在 Framer 里发布的营销站直接有效，对原生应用或 React 代码库没有直接帮助。

另外，Framer 官方 15 日示范，用一条 skill 在几分钟内把官网从暗色切到亮色，Agent 连配色和匹配浅色主题的新图一起换掉，原设计结构不动。

- [官方更新](https://www.framer.com/updates/image-shader-generation)
- [Ayoub Kada 评述](https://www.ayoubka.com/post/framer-shaders-agent-prompt)
- [暗色切亮色示范](https://x.com/framer/status/2122067743956459529)

**2. SysGears：Figma MCP + Playwright MCP 对照实验（11/13）**
工程师 Daria Vetrykush 用同一页面做对照：把 Figma MCP（结构化设计数据、精确值和可复用资源）与 Playwright MCP（在浏览器里核对应效果）合用后，像素差异从 19.10% 降到 0.26%，模型工作时间从 13 分 24 秒降到 6 分 6 秒，成本从 $3.89 降到 $2.58。文章强调工具本身不够：Figma 文件要有变量、可复用组件、Auto Layout 和有意义的图层名；并用 CLAUDE.md 固定「经 Figma MCP 取上下文 → 用项目组件和 token 实现、禁止写死色值和尺寸 → 用 Playwright MCP 对照 Figma 画面改到看不见差异」的流程。建议装 Figma 官方 Claude Code 插件（会带上设计 skills），有设计系统就开 Code Connect。

- [文章](https://sysgears.com/articles/close-enough-isnt-good-enough-making-ai-agents-build-ui-that-matches-the-design/)

**3. CopilotKit：可交互的 A2UI Playground（15 日）**
接周五的 A2UI 1.0 / CopilotKit Open Intelligent UI。CopilotKit 的 Atai Barkai 发布了可交互的 A2UI Playground：向 agent 要一个界面，可逐行看它写出的 A2UI 1.0，并用 CopilotKit 标准目录、shadcn/ui、Material 或自己的组件渲染同一份答案，还能复制一条 prompt 加进自己的应用。已嵌进每个 OpenBot。

- [Playground](https://a2ui.open.bot)
- [介绍](https://x.com/ataiiam/status/2122034672448545148)

Figma 官方 release notes 在 11/12 的 3D Transforms 之后没有新条目。
