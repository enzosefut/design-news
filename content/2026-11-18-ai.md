**AI 辅助设计日报 · 11 月 18 日**

**1. Google Antigravity：从白板草图到端侧语言学习 App，设计走 Figma MCP**
Google Antigravity 官方今天放出约 3 分钟的案例片：Google AI Edge Gallery 团队用 Antigravity 做了完全离线的 XR Language Teacher。流程从白板上的架构草图起笔——用户问 "What is this?" → ML Kit ASR + 图像 → Gemini Nano 4 → 文本 → TTS → 音频。片中能看到一份密集的 Figma 文件（Onboarding、闪卡、Vocab found、Study 等状态流），以及代理在仓库里阅读 `DESIGN.md`、`SITEMAP.md`，并浏览 Android/Kotlin 的 UI 源码。官方帖写明他们用 Figma MCP 把这些设计映射成真实代码；片中 Antigravity 使用的是 Gemini 3.8 Flash High（Local）。成品可在手机或配对的 Android XR 眼镜上运行：对准物体用语音提问，端侧 Gemma 4（经 AICore）配合 ML Kit ASR/TTS 作答，另外还有 Vocab Ninja、Vocab Runner 这类开口练习。出镜的有工程师 Hriday Chhabria、Geonsun Lee，以及 UX 设计师 Jenn Lee。

- [官方视频说明](https://x.com/antigravity/status/2122848700233925006)（11 月 18 日 08:25，Asia/Shanghai）
- [Google AI Edge Gallery](https://github.com/google-ai-edge/gallery/)

**2. 社区：Details MCP 的「Unslopping」演示在传播**
kev（@koppkev）昨晚放出 29 秒演示 *Unslopping a vibecoded website*，把一个典型 AI 生成感的极地旅行站 Isvik Expeditions，按 Declutter、Spacing、Copy、Alignment、Font、Imagery、导航下拉和按钮/主视觉动效逐步收干净。他在回复里说，接上 MCP 并让代理「用一些 Vault 资源把它改好」只花了约 5 秒。Details MCP 把 Claude Code、Cursor、Codex、v0、ChatGPT 接到 3500+ 条人工挑选的线上站点细节：交互按帧排列并附说明，付费 Vault 还带实现代码。远程地址是 `https://api.details.so/mcp`，MCP 包含在付费方案里（Pro 可走 Inspo；Max / Team / Lifetime 含 Vault）。这不是今天新上线的产品，但这条演示在昨日下午（18:12，Asia/Shanghai）之后大量传播；工作流本身值得看：先给代理真实线上参考，再改掉「AI 味」，而不是只靠「做高级一点」这类提示词。

- [演示帖](https://x.com/koppkev/status/2122633959888851130)
- [Details MCP](https://www.details.so/mcp)

**3. Framer Agent 模型选择器加入 GPT-6.2 Astra 与 Sol**
Framer 官方宣布，GPT-6.2 Astra 和 Sol 已出现在 Agent 聊天的模型选择器里。帮助文档对既有 GPT 6 系列的分工仍是：Astra 偏代码组件和带自定义交互的创意布局，Sol 偏页面搭建与 CMS 修改。官方稍后还补了一组 Shader Generation 的提示词示例（该功能已在 11/16 日报里写过）。
