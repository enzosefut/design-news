**AI 辅助设计日报 · 11 月 24 日**

周一日报之后，实质更新是 Figma 把自家 agent 推进到了 FigJam 和 Slides。

**1. Figma agent 正式进入 FigJam 与 Slides：用连接器和附件把材料收上画布，再把讨论收成 Spec 或演示稿**
Figma 产品总监 Jinen Kamdar 在 11 月 23 日的官方博客宣布：Figma agent 已在 FigJam 和 Figma Slides 全面开放，两端都支持连接器（Connectors）和附件。帮助文档写明，目前面向 Professional、Organization、Enterprise；任何能打开这块白板或演示稿的人都可以和 agent 聊天，但让它改内容仍需要编辑权限。桌面应用或网页可用，移动端暂不支持。调用 agent 会按任务复杂度消耗 AI credits。

FigJam 这边，重点是会前准备和会后收束。可通过 `Add context` → `Connectors` 接入外部应用（博客举例 Notion、Google Drive，发行说明还提到 Hex、Slack、Asana；帮助文档写的是 20 多个已验证合作方连接器，也可以自建），或通过 `Add context` → `Add images and files` 附上截图、Figma 文件、文本和 PDF。Figma 设计经理 Megan Bednarczyk 会在设计评审前，让 agent 把先前评审反馈、Slack 讨论和竞品例子拉到已排好的设计旁边，汇总上次共识、待讨论问题，以及竞品里反复出现的模式。评审结束后，框选反馈贴纸，选 `Organize` → `Summarize`，agent 会在原贴纸旁边起草一份 Spec。Specs 技术负责人 Johnny Dallas 则习惯先选中相关贴纸，点 `Ask agent`，提示：`Summarize this discussion as a spec. Include decisions, next steps, and open questions, and review the comments on the board, too.` 因为草稿就在原始反馈旁边，回头对决策和过程都方便。帮助文档还写明，FigJam 里的 agent 可以使用 MCP 连接器、把团队流程存成 skills，也可以搜索网页和其他 Figma 文件；不支持把白板直接发送到 Figma Design、Slides 或 Make。音频和视频附件暂不支持。

Slides 这边，可以从已有材料起稿。Figma 品牌设计师 Jarrod Barretto 做 Config 和内部活动的 keynote 时，会先把高管一起写好的讲稿交给 agent，提示 `Break this up into individual slides so the content flows logically.` 先审大纲，再点 `Generate deck` 出一版幻灯片。发行说明还写了可以从附上的 Spec 大纲和品牌模板起稿，并让 agent 拆开排得太满的页面、锐化 takeaway、按听众起草讲者备注。Jarrod 也会丢一张表格截图，让 agent 按数据生成柱状图，自己只管样式，数字交给 agent；也可以用 CSV 更新已有图表。此外还能改写给不同听众、压缩全文案、请 agent 看故事和版式，或根据讲者备注估算时长。帮助文档提醒：模板只是风格参考，生成结果需要再检查。

社区里，设计师 miggi 演示了在 FigJam 里选中分区或贴纸，让 agent 在白板上生成 Spec markdown，并读取 +1、? 贴纸和评论，给凌乱的共创板排优先级和下一步。
