Figma 在 11 月 20 日的 Workflow Lab 中演示：工程师在画布上汇总 Pickup（虚构市集应用）配送功能的 PRD、Hex 数据、FigJam 流程图、标注设计稿、地图 code layer 和设计系统说明，调用预先配置的 `build-implementation-plan` skill，让 Figma agent 生成实施计划。审核、评论并 @ 设计师修改后，把一条 spec 链接经 Figma MCP 交给 Codex，提示 `Implement this feature`。Specs 处于开放测试，面向全套餐；按 D 或从工具栏插入。手动编辑不消耗 AI credits。
