Canva 在 11 月 24 日凌晨宣布 MCP 正式开放，不再需要候补名单，并重建了给 Agent 用的工具层。Agent 可生成可编辑设计、图片和视频，去背，用 Magic Layers 把平面图拆成图层，并按渠道缩放和导出。自研模型 Canva Craft 也经 MCP 和 API 开放。同时新增面向产品接入的 REST API、扩展后的 CLI，以及用于 API 计费的 service accounts。ChatGPT 和 Claude 的连接器可在对话里做可编辑视频（需先确认时间轴方案；视频目前只在部分市场提供），也可在侧栏改文字和布局后再进 Canva。
