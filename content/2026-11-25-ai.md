**AI 辅助设计日报 · 11 月 25 日**

昨日上午日报之后，实质更新是 Framer 把 Agent 工作流做成可定时、可被站点事件触发的 Automations，并一起推出 Connectors 和 Slack Agent。

**1. Framer 推出 Automations、Connectors 与 Slack Agent：把 Agent 工作流挂到发布和表单上，也可在 Slack 里改站点**
Framer 在 11 月 24 日的产品更新页宣布 Automations、Connectors 和 Slack Agent。官方帖发出时间为 11 月 24 日 23:37（Asia/Shanghai）。入口在 Site Settings 的 Automations 或 Connectors 页签。同日 Academy 课程由 Joseph 发布，官方博客由 Joost Damhuis 写了六种 Slack Agent 用法。

Automations 是保存下来的 Agent 工作流，可手动跑，也可按日程（Hourly、Daily、Weekdays、Weekly、Monthly，使用你的时区）或项目事件触发：Publish、Deploy（需开启 staging）、Branch merge（可限定来源和目标分支，需支持 branching 的方案）、New comment、A/B test status、Form submit。官方举例包括：每次发布做 SEO 检查并把结果发到 Slack、每日分析简报、把表单线索补充信息后路由到合适的地方。最快的做法是在 `Describe an automation…` 里口述任务，让 Agent 填触发器、指令和工具；也可以在普通 Agent 对话里说：`Create an automation that emails me a list of new form submissions every Friday.` 指令用纯语言写清结果，并用 `@` 引用页面、CMS 集合、组件或连接器，用 `/` 添加 skills。触发相关的变量（例如发布时的 Site URL 和 User Name、表单字段）也可以插进指令。表单提交来自访客，Agent 只把它当数据，不会当成指令。

Capabilities 可分别开关 Edit（画布、CMS 和设置）、Publish、Code；三项都关则只读，仍可检查项目并发报告。只报告、不改站点的自动化应关掉这三项。运行记录能看到触发、时间、耗时、credits 和状态（Running、Pending、Success、Failed、Cancelled）；Success 只表示跑完，前几次结果需要人工看。自动化运行时不能中途提问，也不能创建或修改其他 automation。每次运行消耗与 Agent 聊天相同的 AI credits。创建和改 automation 需要编辑站点设置的权限，并以 owner 的权限运行。帮助文档写明更新于 11 月 24 日。

Connectors 让 Agent 在聊天和 Automations 里读写团队已有的外部工具。帮助文档列出的可用连接器包括：Notion（搜索和编辑页面）、Ahrefs（关键词和反向链接）、Typefully（起草和安排社交帖）、Loops（邮件和联系人）、Slack（搜索和发送消息）、BigQuery、Google Analytics、Google Sheets、Google Cloud Resource Manager、Google Docs。连接在 Site Settings → Connectors 完成；在桌面应用里会转到默认浏览器授权。每人、每个项目各自授权，协作者不会共用你的账号。目前不能只开放连接器里的某一项 tool，也不能把自定义 MCP server 加成连接器；要把自己的 AI 客户端接到 Framer，走既有的 Framer MCP。Connectors 帮助文档标注更新于 11 月 20 日，11 月 24 日的官方更新把这项能力与 Automations、Slack Agent 一并作为产品发布写出。

Slack Agent 是另一条路径：在频道里提及 `@Framer` 或给它发 DM，询问站点、拉取分析、做小改动，而不必打开 Framer。帮助文档写明：在 Slack 的 app 容器里使用 AI agent 需要付费 Slack 方案；查看或修改项目目前需要 Design 权限及以上，只读权限不够。官方博客写明 Slack Agent 的改动会开新分支，直播站保持不变，可在 Framer 里验收后再请它合并并发布。六个示例包括：只收紧手机端布局并保持桌面不变、按对话更新 CMS、把上周与再上周的访问对比图发到线程、补 SEO 细节、在线程里微调间距后合并发布，以及从团队报障线程里另开 session 去排查。Slack 连接器和 Slack Agent 不是一回事：前者是 Agent 把 Slack 当工具（例如 automation 往频道发结果，且不支持私信），后者是人在 Slack 里跟 `@Framer` 说话。两边可以分开使用。
