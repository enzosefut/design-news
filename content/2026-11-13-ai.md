今天有两件比较实质的更新。

Figma 的 3D Transforms 对 Full 席位进入开放测试。文字、图片、矢量、Frame 和组件都能沿 X、Y、Z 轴旋转，给父级 Frame 加上透视后，里面的元素会排进同一个立体场景；效果是非破坏性的，也能和着色器、Figma Motion 叠用。Brand Studio 做发布片时的用法更具体：设计师让 Figma Agent 去算 Z 轴间距、搭几何体，或直接让 Agent 写一个生成式插件，把元素排成网格、螺旋、圆环或随机散布，人再改构图。交给开发时，在 Dev Mode 选中图层就能复制对应的 CSS transform；编码代理也能通过 Figma MCP 读取和创建这些 3D 设计。详见 [Figma 公告](https://x.com/figma/status/2120926665790681354) 和 [官方博客](https://www.figma.com/blog/how-3d-transforms-and-figmas-agent-brought-a-launch-video-to-life/)。

Vercel 发布了 UI SDK（beta），由 shadcn 和 Shu Ding 主导。它不是又一套组件库，而是把弹层、选择、键盘导航、焦点、拖放等拆成 50 多个可复用行为（如 `createPopup`、`createSelection`、`createTypeahead`），再让 Agent 按需组合成 Select、Combobox，或还没人做过的新控件；React、Vue、Svelte、Solid 和 Web Components 都能用。配套有 Agent Skill，安装是 `npx skills add vercel-labs/ui --skill ui-sdk`。另一头，生成出来的界面也是给 Agent 用的：应用会暴露 WebMCP，代理可以直接读控件、操作界面，而不用靠截图，官方称速度能到两倍以上、成本不到一半。详见 [Vercel 公告](https://x.com/vercel/status/2120950020249895314)、[文档](https://ui-sdk.dev/) 和 [GitHub 仓库](https://github.com/vercel-labs/ui)。

接昨天的 A2UI 1.0，[CopilotKit](https://x.com/CopilotKit/status/2120958749980639561) 今天推出了 Open Intelligent UI，可以在自己的应用里用自有组件或他们的目录做生成式界面。
