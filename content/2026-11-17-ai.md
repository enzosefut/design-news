**AI 辅助设计日报 · 11 月 17 日**

**1. 补漏：Anima 发布 Agentic Canvas（11/15）**
Anima 联合创始人兼 CEO Avishay Cohen 推出免费、免登录的浏览器设计画布（挂在 AgentGrid.io 品牌下）。人和 MCP 代理编辑的是同一份真实 HTML/CSS：画框就是页面，Auto layout 对应 flexbox，网格就是 CSS Grid。可接 Claude、ChatGPT、Claude Code、Codex、Cursor 等；代理工作时需保持画布标签页打开。可以从 HTML、Figma 选区、图片入手，或让代理直接生成。可导出 HTML/PNG/SVG/PDF。文件默认只存在当前浏览器，发布公开链接才需账号。Product Hunt 11/15 日榜第 6。

- [画布](https://agentgrid.io/canvas)
- [博客](https://animaapp.com/blog/agentic/canvas/)

**2. Marcel / Underlay：用 Claude Code 经 Figma 插件 API 直接改文件，做了 490 屏（244 桌面 + 246 移动）**
Marcel（@marcelkargul）介绍 Underlay 用 Claude Code 经 Figma 插件 API 直接改文件做了 490 屏。方法要点：

1. 颜色全部走 Figma 变量，禁止手写 hex（基础色板 244 个变量；主题一层；再按用途绑定 token）。他们踩过的坑是：Figma 绑定变量时会存一份 fallback，Claude 写成了黑色，截图看起来正常，打开文件才暴露。
2. 用一份 `design-system.md` 做跨会话记忆，每条规则一句话，附原因和日期。
3. 不预先堆组件库，先画真实屏幕，再把反复出现的结构收成 6 个块：list card、sheet、form sheet、dock、bottom bar、empty state。
4. 每批之后跑审计脚本（截图看不出的 fallback / 裸 hex / 文字样式 / 图标描边 / clip 等）。一次查出 112 个图标描边错误，另一次发现 858 个框被错误设置了 clip。
5. 每次纠正都会写回规则，能自动化的补进审计，并回灌到已画过的页面（例如把间距收到 8px 后，59 个按钮一起改掉）。

文中也写得很清楚：Claude 捆住了体量，但没有做任何设计决策；品味和判断仍在团队。文章标题是 *how we use AI agents for product design in 2026*。

- [Marcel 的帖子](https://x.com/marcelkargul/status/2122430710053019994)

**3. Kaggle 推出 Code2Video Arena**
Kaggle 今天与 HeyGen、HyperFrames 一起上线 Code2Video Arena，建立在 HeyGen 的 Code2Video Benchmark 上，用来比较模型把 brief 写成动态设计（生成 HyperFrames 代码）的能力。官方说明覆盖 168 条精选 brief。评测场对同一 brief 生成的两条视频做盲投。截至 11 月 16 日共 5,541 票，目前领先的是 Gemini 4 Carbon (High)，其后是 Claude Opus 5.5 (High) 和 GPT-6 Astra (High)。

- [排行榜](https://www.kaggle.com/benchmarks/heygen/code2video-arena)
