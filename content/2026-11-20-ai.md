**AI 辅助设计日报 · 11 月 20 日**

**1. Figma：Dev Mode 里可以直接问 Agent——看懂设计、对比版本、要代码片段，并生成批量下载链接**
Figma 产品更新（11 月 19 日）写明：现在可以在 Dev Mode 里调用 Figma agent，用来检查和理解设计。帮助文档的能力表把这些标为已支持：询问组件交互、找出本可用已有变量的图层；询问如何用 CSS Grid / Flexbox 实现，或要一段 React 代码片段；用视觉 diff 或变更列表对比组件 / 设计版本；以及准备导出资源（例如生成图标组件的 SVG 下载链接，或变量的 CSS）。Agent 不会替你直接导出文件，而是生成下载链接让你自己保存。官方说明：Dev 席位可以对话但不能改共享设计，Full 席位也可以让 agent 做修改；Dev Mode 在 Starter 方案以及 View / Collab 席位上不可用。这是面向开发协作的 agent 能力，不是新的画布生成模型。昨日上午的日报写了「一条提示词出多图」，这条 Dev Mode 更新当时还没有收进来。

- [产品更新](https://www.figma.com/release-notes/)（11 月 19 日）
- [帮助文档](https://help.figma.com/hc/en-us/articles/37998629035799-Work-with-the-Figma-agent-in-design-files)

**2. Gemini Mac 应用上线 computer use：可在后台窗口把草图做成 Blender 里绑好骨骼的 3D 模型，屏幕和光标仍归你**
Google 官方（Gemini 应用产品负责人 Michael Friedman）宣布：Mac 版 Gemini 应用新增 computer use。用自然语言描述任务，Gemini 会在独立的后台窗口里点击、滚动、打字、翻菜单、填表，覆盖本地文件、桌面应用和网页；聊天里有实时预览，主屏幕和光标仍可用。官方演示就是把一张草图做成 Blender 里绑好骨骼的 3D 模型；博客还写到可在常用设计软件里批量调色，或搭建复杂 3D 场景。你选择它能访问哪些应用，可随时暂停，关键操作需批准；遇到登录或支付会停下来。正在向美国英语用户推送，需 Apple Silicon + macOS Sequoia 15.0+，面向 18 岁以上个人 Google 账号的 Google AI Plus / Pro / Ultra 订阅者。

**3. Ideogram 4.6：原生 4K，主打精确改图（品牌 hex、产品细节、遮罩编辑）**
Ideogram 官方发布 4.6（官方写明发布于 11 月 19 日）：原生 4K 出图（不是先出图再放大，官方称最高 4096×4096），强调改图时指定区域以外的像素更少漂移，颜色更准。官方模型页给出与 4.5 对比的「可用结果」比例（High quality、同一组请求）：角色一致性 85%（4.5 为 69%）、把物体改成指定品牌 hex 83%（46%）、修复产品照片小缺陷 86%（61%）、产品摆拍 / 改风格 / 改标 88%（66%）、只改涂抹遮罩区域 90%（82%）。在 Ideogram Image 应用的模型选择器里选 Ideogram 4.6（不要用 Auto），也可走 API：`POST /v2/image/precise-edit/ideogram-4-6` 做局部精确编辑，`POST /v2/image/generate/ideogram-4-6` 生成或带最多五张参考图编辑。官方页还写它在 Rapidata Multi-step Image Edit 榜上排第一。官方跟帖称希望打开电商和产品摄影场景。
