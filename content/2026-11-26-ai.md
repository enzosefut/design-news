**AI 辅助设计日报 · 11 月 26 日**

昨日上午日报之后，需要补上 Canva 在 11 月 24 日凌晨宣布的 MCP 正式开放，以及同一波更新里的视频生成和 Magic Layers。

**1. Canva MCP 正式开放：重建了给 Agent 用的工具层，并加上视频生成、Magic Layers、REST API 与 CLI**
Canva 在 11 月 23 日 18:01（UTC，Asia/Shanghai 为 11 月 24 日 02:01）连发官方帖，新闻稿同步宣布：Canva MCP 正式开放，不再需要候补名单。此前接入主要限于开发者社区，以及与 OpenAI、Anthropic 等合作方已经做好的连接器。现在可以在 Canva Developer Portal 创建应用、登记回调地址并打开 MCP 访问。帮助文档写明：MCP 仍要求每个用户单独做 OAuth，并需要有自己的 Canva 账号；权限跟该用户在 Canva 里对设计或资源的权限一致。

这一次不仅是放开名单，还重建了 MCP 的工具层：合并重叠能力，让 Agent（官方也提到能力较弱的模型）更容易选对工具、给出正确输入，并用更少上下文得到可预期的结果。新闻稿列出 Agent 现在可以直接调用的能力：生成可在 Canva 里继续编辑的设计、独立图片或视频，去背，把平面图或平面图形拆成可编辑的分层设计（Magic Layers），按渠道缩放，导出成品，以及检索已有设计和模板并用数据做个性化。自研图像模型 Canva Craft 也通过 MCP 和 API 开放。

连接方式变成三条。MCP 适合由 Agent 按提示词自行选择工具，例如让助手准备产品发布物料，再交回一套可编辑的多尺寸设计。REST API 适合把能力嵌进自己的产品，目前写明已开放的有设计生成、图像生成、去背和 Magic Layers；并新增 service accounts 和 API billing，便于不依赖某个员工登录会话的高并发自动化——客户可以在你的产品里用这些能力，而不必每人登录 Canva。官方帮助文档同时写清：MCP 本身仍是按用户授权，没有改成组织级账号。Canva CLI 则从原来主要在编辑器里创建 Apps，扩展到创建设计、跑 Autofill，以及在命令行调用 REST API；官方称 10 月已有 72% 的键入命令来自 Agent。

面向 ChatGPT 和 Claude 的连接器是同一波更新的另一面。第二篇新闻稿写明：可以在对话里上传图片和品牌资产，用自然语言写 brief，Canva MCP 会搭配包括 Seedance 2.5 在内的模型和按提示选中的模板（产品演示、开箱、虚拟试穿等），先给出带时间轴的制作方案供你确认，再生成可编辑视频，并接到 Canva 的完整视频编辑器去做字幕、去背、裁切、排期和发布。若附上产品视觉，reference binding 用来保持外形、颜色和标签一致。官方写明：新工具在全球可用，但取决于合作方是否开放；在 ChatGPT 和 Claude 里用 Canva MCP 做视频，目前只在部分市场提供。Claude 这条路径需要付费订阅。生成结果可在 ChatGPT、Claude 的侧栏里改文字、换图、调布局、浏览模板，再一键进 Canva 做更重的编辑。Autofill 填充品牌模板现面向 Pro、Business、Education 和 Enterprise。帮助文档的套餐表与之一致：缩放、Autofill、Brand Kit 和品牌模板需要 Pro 及以上；Free 对 `resize-design` 有有限试用。工具是否出现还取决于你用的助手。
