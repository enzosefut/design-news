**AI 辅助设计日报 · 2026-11-11**

昨日日报之后有几条实质更新。

**1. Claude 的 Interactive connectors 升级：完整应用可嵌进对话旁**
Anthropic 开始在 Web / Desktop 全计划推送：Interactive connectors 不再只是对话里的小预览，可以把工具开在聊天旁边或全屏，Claude 能直接在打开的工具里改内容（批准方式与连接器操作相同）。技术上是 MCP Apps 的扩展（app tools + 内嵌站点），开发者能力处于 public preview。

设计相关、官方点名已在目录里的有 Canva、Adobe（修图、给 PDF 加亮/编辑/脱敏）、Webflow。Figma 被单独写成「也在建设集成」，不要理解成今天就能在 Claude 里完整编辑 Figma 文件；既有的 Figma interactive connector 仍偏审阅/标注和 FigJam 图表。

- [公告](https://claude.com/resources/articles/interactive-connectors-full-tool)
- [帖子](https://x.com/claudeai/status/2120206365759094857)

**2. Adobe MAX：Creative Agent 铺开，本地 MCP 要到 2027 年初私测**
11 月 10 日（Adobe 官方新闻稿；TechCrunch 发于太平洋时间早上，北京时间当晚）Adobe 在 MAX 宣布：Adobe Creative Agent 进入 Premiere、Illustrator、InDesign、After Effects、Frame.io，Photoshop 在 beta 应用里。可编排多步工作流（例如在 Premiere 里给整条序列套效果、追踪遮罩主体、统一调色/曝光）。

更关键的是预告的**本地 MCP**：第三方 agent（ChatGPT / Claude / Gemini 等）将直接在本机原生工程文件里改 Photoshop、Illustrator、Premiere、After Effects，图层、矢量、bin、序列仍可编辑，也可和其他 MCP 工具（如 Google Drive、Slack）串起来。官方写明：**2027 年初 private beta，现在还用不了。**

同一场还有 Firefly Design（beta，栅格/矢量/动效/3D/印刷同一画布）、Firefly Graph（beta，可重复工作流），以及 **Firefly Builder（private beta）**：自然语言出网站/演示/App 交互原型，再在画布上改元素，靠设计系统保持一致性。这是偏设计到代码原型的方向，不是生产代码。

- [官方](https://news.adobe.com/news/2026/11/adobe-transforms-creative-cloud-tools)
- [TechCrunch](https://techcrunch.com/2026/11/10/adobe-adds-more-ai-to-its-products-and-launches-an-mcp/)

**3. Dan Kornas 分享 Scenario Agent Skills**
给 coding agent 的资产生成工作流，而不是再写一条出图 prompt。技能包教 agent 经 Scenario MCP 发现模型、核对输入 schema、跑生成并取回结果，覆盖图像（含参考图、蒙版、产品图）、视频/音频、游戏与 3D 资产，以及角色/风格一致性和带成本、延迟、contact sheet 的模型对比。需要已连接的 Scenario MCP 和账号；仓库 MIT，生成本身不免费。刚发布，社区反响还很小。

- [帖子](https://x.com/DanKornas/status/2120327150901289082)
- [仓库](https://github.com/scenario-labs/skills)
- [文档](https://mcp.scenario.com/docs/resources/agent-skills)
