Figma Agent 进入 Dev Mode：看懂设计、对比版本、要代码片段，并生成批量下载链接

Figma

Figma 在 11 月 19 日的产品更新中写明：可在 Dev Mode 里调用 Figma agent，用来检查和理解设计、对比版本、要代码片段，并生成批量下载链接。帮助文档标明 Agent 不会替你直接导出文件，而是生成下载链接让你自己保存。Dev 席位可以对话但不能改共享设计；Full 席位也可以让 agent 做修改。Dev Mode 在 Starter 方案以及 View / Collab 席位上不可用。
